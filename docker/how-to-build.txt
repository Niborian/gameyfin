Normal application build (from repository root):

Windows:
  .\gradlew.bat build "-Pvaadin.productionMode=true"

Linux/macOS:
  ./gradlew build -Pvaadin.productionMode=true

Production builds require the existing signing environment variables:
  GAMEYFIN_KEYSTORE_PATH, GAMEYFIN_KEYSTORE_TYPE, GAMEYFIN_KEYSTORE_PASSWORD
Keep their values private; do not pass passwords as command arguments.

The redundant PowerShell/Bash image-builder helpers were removed. Use the reviewed
GitHub Actions candidate workflow for versioned image publication; see docker/README.md.
Neither building nor publishing authorizes deployment or latest promotion.
